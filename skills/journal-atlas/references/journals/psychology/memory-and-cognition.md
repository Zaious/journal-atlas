- Memory / attention / learning research
- Replication studies (welcomed)
- Authors comfortable with Psychonomic Society publication norms

### Not Recommended For

- Applied cognitive psychology without theoretical depth
- Pure neuroimaging without behavioral cognitive contribution
- Theoretical-only work without empirical support
