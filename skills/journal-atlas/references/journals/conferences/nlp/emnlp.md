## Strategic Notes

### Hard Blockers

- English-only claims without multilingual disclaimer
- Missing dataset documentation (data sheets / model cards)
- Missing error analysis for empirical NLP claims
- Unethical data collection without disclosure

### Soft Tax

Medium-High. ARR cycle model allows revision but venue commitment phase still selective.

### Best Suited For

- Novel NLP tasks with dataset release
- Multilingual / low-resource language work
- Computational linguistics with rigorous evaluation
- LLM analysis / probing papers

### Not Recommended For

- English-monolingual claims without justification
- Pure prompt engineering without methodological contribution
- Position papers without empirical backing
