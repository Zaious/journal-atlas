## Strategic Notes

### Hard Blockers

- Missing ablation studies on key components
- Unclear or overclaimed novelty
- No released code (especially for empirical claims)
- Unfair or outdated baselines
- Missing reproducibility checklist (NeurIPS / ICML)

### Soft Tax

High. Reviewer cycles within rebuttal demand new experiments. Plan for AC-discussion-phase iteration. Code release before submission deadline strongly recommended.

### Best Suited For

- Novel ML methods with strong empirical validation
- Theoretical contributions with proof sketches
- New benchmarks / datasets (often via Datasets and Benchmarks track for NeurIPS)
- Applications papers demonstrating algorithmic innovation

### Not Recommended For

- Application papers without algorithmic novelty
- Empirical work without ablations or baselines
- Position papers without empirical backing
