---
name: ja-similar
description: "Find journals most similar to a target journal. Useful for lateral discovery or finding alternatives beyond the curated Rejection Fallback Chain."
---

Run `scripts/similar_journals.py` with the journal specified in $ARGUMENTS.

Present results with the similarity-dimension breakdown so the user sees WHY each journal is similar. Note the distinction from the Rejection Fallback Chain: this is algorithmic discovery, not curated strategy.
